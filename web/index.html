    How this project was built

    One pipeline, six stages. Each stage is a separate Python file.

      Limitations

      • The air quality values come from a computer model (CAMS, via Open-Meteo), not from monitors on the ground in Lahore, so real readings can differ.
      • One grid point is used for the whole city.
      • The correlations show association only. They do not prove that weather causes pollution changes.

      Data: Open-Meteo Air Quality and Historical Weather APIs. WHO 2021 air quality guidelines.
